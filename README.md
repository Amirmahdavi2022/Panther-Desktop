# Panther Desktop

نسخه‌ی ویندوز پنتر. یک پنجره، یک دکمه، بدون نصب درایور و بدون دسترسی ادمین.

## این نسخه چطور کار می‌کند

موتور به صورت یک برنامه‌ی جداگانه بالا می‌آید و یک **پروکسی SOCKS5 روی `127.0.0.1:1819`** می‌سازد. برنامه فقط آن را اجرا و مدیریت می‌کند. یعنی نه درایور TUN لازم است، نه دسترسی مدیر، و نه چیزی در سیستم نصب می‌شود.

بعد از اتصال، همان آدرس را در مرورگرت وارد کن. در فایرفاکس از Settings → Network Settings، و در کروم با افزونه‌های پروکسی مثل Proxy SwitchyOmega.

## موتورها

| موتور | وضعیت در این نسخه |
|---|---|
| **Aether** (WARP / MASQUE) | ✅ فعال |
| **Global** (Psiphon) | ⏳ در کد آماده است، هسته‌اش هنوز همراه نسخه نیست |
| **Prowl** (Xray) | ⏳ همان |

اگر موتوری همراه نسخه نباشد، برنامه صادقانه همان را می‌گوید و چیزی را وانمود نمی‌کند.

## ساخت

بیلد روی GitHub Actions انجام می‌شود، پس به هیچ ویندوزی برای ساختن نیاز نیست.

- یک تگ `v*` بزن، یا از تب Actions همان ورک‌فلو را دستی اجرا کن.
- CI هسته‌ی Aether را از ریپوی رسمی‌اش می‌گیرد، checksum را بررسی می‌کند، و بدون هسته اجازه‌ی بیلد نمی‌دهد.
- خروجی یک نصب‌کننده‌ی NSIS است که بدون دسترسی ادمین نصب می‌شود.

برای بیلد محلی (اگر ویندوز داری):

```
cargo tauri build
```

## ساختار

```
src/                رابط کاربری (HTML/CSS/JS ساده، بدون مرحله‌ی build)
src-tauri/src/engines.rs   اجرای موتور، تشخیص بالا آمدن، خاموش کردن
src-tauri/src/main.rs      لایه‌ی نازک Tauri
.github/workflows/         بیلد و انتشار ویندوز
```

`engines.rs` عمداً هیچ وابستگی‌ای به Tauri ندارد تا بشود جدا کامپایل و تستش کرد. CI هم دقیقاً همین کار را قبل از بیلد ویندوز انجام می‌دهد.

## نکته‌ها

- نصب‌کننده امضای دیجیتال ندارد، پس ویندوز ممکن است هشدار SmartScreen بدهد. این درباره‌ی ناشناس بودن امضاست، نه محتوای برنامه.
- پروکسی SOCKS رمز عبور ندارد و فقط روی `127.0.0.1` باز می‌شود. آن را روی شبکه باز نکن.
