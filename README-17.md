# Panther Desktop

نسخه‌ی ویندوز پنتر. همون حس نسخه‌ی اندروید رو داره: یه دکمه می‌زنی و کل سیستم از تونل رد میشه. مرورگر، تلگرام، بازی، هر برنامه‌ای که باز باشه. دیگه لازم نیست پروکسی تنظیم کنی یا دست به تنظیمات ویندوز بزنی.

---

## دانلود و نصب

1. از بخش [Releases](https://github.com/Amirmahdavi2022/Panther-Desktop/releases) آخرین نسخه رو بگیر. فایلی که لازم داری همونیه که آخر اسمش `setup.exe` داره.
2. بازش کن و نصب کن. نصب برای همون کاربر ویندوزیه که الان باهاش لاگین هستی.
3. اگه ویندوز صفحه‌ی آبی SmartScreen نشون داد نگران نباش. روی **More info** بزن و بعد **Run anyway**. این هشدار فقط به خاطر اینه که نصب‌کننده امضای دیجیتال پولی نداره و به خود برنامه ربطی نداره.

> برنامه با ویندوز ۱۰ و ۱۱ (۶۴ بیتی) کار می‌کنه.

---

## ⚠️ حتما با دسترسی Administrator اجرا کن

این مهم‌ترین نکته‌ی کل این صفحه‌ست.

پنتر برای اینکه کل سیستم رو ببره تو تونل، یه کارت شبکه‌ی مجازی به اسم `Panther` می‌سازه. ویندوز این اجازه رو فقط به برنامه‌ای میده که با دسترسی ادمین باز شده باشه. پس:

- موقع باز کردن برنامه، ویندوز می‌پرسه اجازه میدی یا نه (همون پنجره‌ی UAC). **Yes** رو بزن.
- مخصوصا برای موتور **Global** این کار واجبه. بدون ادمین اصلا بالا نمیاد.
- اگه یه وقت نپرسید، یا خطای «ساخت تونل ممکن نشد» گرفتی، برنامه رو ببند، روی آیکونش راست‌کلیک کن و **Run as administrator** رو بزن.

**یه ترفند که هر بار یادت نره:** روی آیکون پنتر راست‌کلیک کن، برو تو **Properties**، تب **Compatibility**، تیک **Run this program as an administrator** رو بزن و OK. از این به بعد همیشه خودش با ادمین باز میشه.

## چطوری وصل شم

1. برنامه رو (با ادمین) باز کن.
2. پایین صفحه موتورت رو انتخاب کن: **Aether** یا **Global**.
3. اگه Global رو زدی، یه قسمت «کشور خروجی» کنارش باز میشه. می‌تونی رو **خودکار (بهترین سرور)** بذاری یا خودت کشور انتخاب کنی.
4. دکمه‌ی گرد وسط رو بزن و صبر کن تا سبز بشه و بنویسه «متصل شدی».

بعد از وصل شدن، زیر دکمه سه تا چیز می‌بینی: مدت اتصال، موتوری که روشه، و آی‌پی خروجی با پرچم کشورش. اون آی‌پی و پرچم رو خود برنامه از اون طرف تونل می‌پرسه، پس همونیه که سایت‌ها واقعا می‌بینن.

برای قطع کردن هم دوباره همون دکمه رو بزن. اگه برنامه رو ببندی، تونل هم خودش خاموش میشه و اینترنتت عادی برمی‌گرده.

## موتورها

| موتور | به درد چی می‌خوره | زمان اتصال |
|---|---|---|
| **Aether** | استفاده‌ی روزمره، سریع و پایدار | معمولا چند ثانیه، بار اول تا ۲ دقیقه |
| **Global** | وقتی کشور خروجی مهمه، مثلا برای سرویس‌های هوش مصنوعی یا سایت‌هایی که آی‌پی ایران رو قبول نمی‌کنن | تا ۳ دقیقه |
| **Prowl** | هنوز تو نسخه‌ی ویندوز نیست | — |

**یه نکته درباره‌ی Aether:** این موتور آی‌پی و اپراتورت رو مخفی می‌کنه و از فیلتر رد میشه، ولی کشورت رو عوض نمی‌کنه. سایت‌ها ممکنه هنوز فکر کنن ایرانی. این رفتار خود شبکه‌ایه که Aether روش کار می‌کنه و باگ برنامه نیست. اگه کشور برات مهمه برو سراغ Global.

### چرا Global اینقدر طول می‌کشه

Global تنهایی رو این شبکه‌ها راه پیدا نمی‌کنه، چون هم سرورهاش فیلترن هم جایی که لیست سرورها رو ازش می‌گیره. واسه همین پنتر اول Aether رو بالا میاره و بعد Global رو **از داخل** تونل Aether وصل می‌کنه. دو تا تونل پشت سر هم یعنی زمان بیشتر، و یه کم سرعت کمتر از Aether خالی.

اگه مرحله‌ی دوم بالا نیاد، برنامه مرحله‌ی اول رو هم خاموش می‌کنه. یه اتصال نصفه‌نیمه از بیرون شکل اتصال سالمه ولی هیچی ازش رد نمیشه، پس بهتره اصلا وصل نشون نده.

### کشور خروجی

- **خودکار** یعنی موتور خودش بهترین سروری که الان هست رو انتخاب می‌کنه. اگه فقط می‌خوای وصل شی همین بهترینه.
- بقیه‌ی کشورها رو خودت دستی انتخاب می‌کنی. نزدیک ۳۰ تا کشور هست و بالای لیست یه جستجو هم داره.
- اگه کشوری که زدی اون لحظه سرور آزاد نداشت، موتور خودش میره رو خودکار و برنامه زیر دکمه بهت میگه چی شد. مثلا «آلمان الان در دسترس نبود، خروجی: هلند». یعنی الکی وانمود نمی‌کنه.

## اگه یه جا گیر کردی

**وسط کار خطا داد یا اتصال پرید (با هر دو موتور پیش میاد)**
یه وقتایی وسط کار این اتفاق می‌افته. راه‌حلش ساده‌ست: دکمه‌ی اتصال رو **دوبار** بزن، یعنی یه بار قطع و یه بار دوباره وصل. تقریبا همیشه با همین درست میشه. اگه برنامه خودش قطع شده بود و نوشته بود «اتصال برقرار نشد»، یه بار زدن کافیه.

**نوشت «ساخت تونل ممکن نشد»**
یعنی برنامه با ادمین باز نشده. بخش ادمین بالا رو ببین.

**نوشت «این موتور در این نسخه همراه برنامه نیست»**
فایل موتور کنار برنامه پیدا نشده. معمولا آنتی‌ویروس برش داشته. پنتر رو از آنتی‌ویروس استثنا کن و یه بار دیگه نصبش کن.

**Global خیلی طول کشید و وصل نشد**
یه بار دیگه امتحان کن و کشور رو بذار رو خودکار. اگه باز نشد، اول با Aether تنها امتحان کن ببین اون بالا میاد یا نه. اگه Aether هم وصل نشد، مشکل از مرحله‌ی اوله و Global هم نمی‌تونه بیاد.

**یه وی‌پی‌ان دیگه هم رو سیستم دارم**
بهتره موقع استفاده از پنتر بقیه‌ی وی‌پی‌ان‌ها رو خاموش کنی، مخصوصا اونایی که حالت TUN دارن (مثل v2rayN تو حالت TUN). دو تا برنامه که بخوان همزمان کل ترافیک سیستم رو بگیرن با هم دعواشون میشه.

**لاگ‌ها کجان**
اگه خواستی مشکل رو گزارش بدی، لاگ‌ها اینجان:

```
%APPDATA%\xyz.jmc.panther.desktop\logs
```

این آدرس رو تو نوار آدرس File Explorer بزن. فایل‌های `aether.log`، `global.log` و `tunnel.log` رو بفرست تو کانال.

## پشت صحنه چه خبره

برای کسایی که کنجکاون:

- موتور به شکل یه برنامه‌ی جدا اجرا میشه و یه پروکسی SOCKS5 رو `127.0.0.1` باز می‌کنه. Aether رو پورت `1819` و Global رو `1820`.
- بعد [sing-box](https://github.com/SagerNet/sing-box) یه کارت شبکه‌ی مجازی به اسم `Panther` می‌سازه، ترافیک همه‌ی برنامه‌ها رو می‌گیره و می‌فرسته به همون پروکسی. خود موتورها از تونل مستثنان، وگرنه ترافیکشون می‌افتاد تو خودشون.
- DNS هم از داخل تونل جواب داده میشه، پس اپراتورت نمی‌بینه چه سایت‌هایی رو باز می‌کنی.
- IPv6 عمدا بسته‌ست، چون موتورها فقط IPv4 دارن. اینطوری برنامه‌ها سریع میرن سراغ IPv4 و چیزی از کنار تونل نشت نمی‌کنه.
- آدرس‌های شبکه‌ی خونه (مودم، پرینتر و...) مستقیم میرن و از تونل رد نمیشن.

## ساختن از سورس

بیلد کامل روی GitHub Actions انجام میشه. یه تگ `v*` بزن یا از تب Actions ورک‌فلو رو دستی اجرا کن. CI این کارا رو پشت سر هم می‌کنه:

1. منطق موتورها رو روی لینوکس تست می‌کنه
2. ساختار پروژه رو می‌چینه
3. هسته‌ی Aether رو از ریلیز رسمیش می‌گیره و checksum رو چک می‌کنه
4. هسته‌ی Global رو از سورس با Go می‌سازه
5. sing-box رو می‌گیره و با هش ثابت چک می‌کنه
6. اگه هر کدوم از هسته‌ها نباشه بیلد رو متوقف می‌کنه
7. نصب‌کننده‌ی NSIS رو می‌سازه و میذاره تو Releases

بیلد محلی رو ویندوز:

```
python -m pip install pillow
bash assemble.sh
cargo tauri build
```

### چرا همه‌ی فایل‌ها تو ریشه‌ن

این ریپو از گوشی نگهداری میشه و آپلودر وب گیت‌هاب نمی‌تونه پوشه بسازه. واسه همین همه چی صاف تو ریشه‌ست و `assemble.sh` موقع بیلد ساختار واقعی Tauri رو می‌سازه. لوگو هم به شکل متن base64 تو `logo.b64` هست و `make-icons.py` همه‌ی آیکون‌ها رو ازش درمیاره، چون آپلود فایل باینری از گوشی قابل اعتماد نیست.

| فایل تو ریشه | جای واقعیش موقع بیلد |
|---|---|
| `app.index.html`، `app.styles.css`، `app.main.js`، `app.flags.js` | `src/` |
| `tauri.conf.json`، `Cargo.toml`، `build.rs` | `src-tauri/` |
| `capabilities.json` | `src-tauri/capabilities/default.json` |
| `engines.rs`، `main.rs` | `src-tauri/src/` |
| `live.rs` | `src-tauri/tests/` |
| `logo.b64` | ازش `src-tauri/icons/*` و `src/logo.png` ساخته میشه |

### تست‌ها

`engines.rs` عمدا هیچ وابستگی‌ای به Tauri نداره که بشه جدا کامپایل و تستش کرد. `live.rs` هم هسته‌های قلابی اجرا می‌کنه که واقعا پورت باز می‌کنن و سه تا چیز رو چک می‌کنه:

- اتصال تک‌مرحله‌ای درست بالا بیاد
- زنجیره‌ی دومرحله‌ای هر دو سرش بالا بیاد و رو پورت بیرونی سرویس بده
- اگه هسته‌ی دوم نبود، کل زنجیره خاموش بشه و چیزی نصفه نمونه

CI همه‌ی اینا رو قبل از بیلد ویندوز اجرا می‌کنه.
